# Pokaimon documentation

Pokaimon is a turn-based browser game that teaches practical AI-model selection through staged problem battles.

Start with [Game Design](GAME_DESIGN.md) for the product contract, [Implementation Plan](IMPLEMENTATION_PLAN.md) for the vertical-slice roadmap, and [MVP Status](MVP_STATUS.md) for completed phases, verified CI and release blockers.

[AG-UI Protocol](AGUI_PROTOCOL.md) documents the model-agnostic streaming boundary; [Security Review](SECURITY_REVIEW.md) covers current controls, rights, and remaining risks. Development-agent instructions are in [root AGENTS.md](../AGENTS.md), with complete official skills in the hidden .agents/ directory.

**Status:** Phases 0 to 4 are implemented and automated checks pass. GitHub Pages still needs repository-owner enablement before the first public phone playtest. This MVP simulates battles and makes no paid provider calls.
